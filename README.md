# DC Aggregation Tool

[下载最新版 Windows 安装包](https://github.com/asfafwdrawdf/dc-tool-updates/releases/latest)

下载发行版中的 `DC-Aggregation-Tool-Setup-版本号.exe`，双击安装。
适用于 Windows 10 / 11 的 64 位系统，安装后无需另外安装 Python 或 Node.js。

安装带在线更新功能的版本后，点击软件右上角的版本号，检查、下载并重启更新。
使用者无需 GitHub 账号。更新前会备份软件中的本地数据。

CloakBrowserDesktop 需要用户单独安装，软件会自动检测并连接。
[CloakBrowserDesktop 官方下载](https://github.com/yt2399/CloakBrowserDesktop/releases)

本仓库存放公开安装包和更新文件。程序的 GitHub 源码仓库保持私有。
